How to Cite and Reuse This Material#

Creative Commons Attribution 4.0 International (CC BY 4.0) license.

You are free to:

  • share this material in any medium or format,

  • adapt, remix, and build upon it for any purpose,

provided that appropriate attribution is given.

Suggested Citation#

If you use or adapt material from this book, please cite it as an online book. A recommended citation format is:

Quarles, B. (Year). College Physics. East Texas A&M University.
Jupyter Book. URL

For example, using the current repository information:

Quarles, B. (2026). College Physics. East Texas A&M University.
Jupyter Book. https://github.com/saturnaxis/IntroPhysics

If you are citing a specific chapter, section, figure, or exercise, include its title and provide the direct URL when possible.

Because this book is a living document, you may also include the date on which you accessed the material.

BibTeX Entry#

@book{QuarlesCollegePhysics,
  author    = {Quarles, Billy},
  title     = {College Physics},
  year      = {2026},
  publisher = {East Texas A\&M University},
  note      = {Jupyter Book},
  url       = {https://github.com/saturnaxis/IntroPhysics}
}
